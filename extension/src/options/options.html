教务系统自动登录

宁夏大学教务管理系统（jwgl.nxu.edu.cn）自动填写账号、识别验证码并登录。

账号

用于登录教务系统的学号与密码。

密码只保存在本机 chrome.storage.local，不会上传到任何服务器，也不会同步到你的 Google 账号。 但本机存储并非加密保险箱，请不要在公用或共享电脑上保存密码。

服务器地址

按顺序尝试，第一个为主地址。只填域名或 IP 时会自动补上 https://。

保存时，如果列表里出现默认域名以外的地址，扩展会请求该域名的访问权限（用于读取验证码图片、注入登录脚本）。 这个请求必须由你在保存时确认；拒绝后该地址仍会保留，但无法自动登录。

常见备用地址（校园网内网 IP）

点击即可填入一个备用地址，保存后扩展会请求该域名的访问权限。

验证码识别

决定验证码怎么得到。不确定就选「手动输入」，不需要任何配置。

验证码识别方式

到 百度智能云 · 通用文字识别 开通服务并创建应用，即可获得密钥；免费额度足够日常登录使用。识别结果是纯数字/字母的验证码。

图片会以 dataURL 文本提交（字段名默认 image）。结果路径支持 a.b.c 形式， 例如 result、data.text，可用于兼容 ddddocr 一类的自建服务。

手动输入模式不需要任何配置：登录时页面右上角会弹出面板，显示验证码图片并等待你输入。 这也是自动识别失败时的人工兜底。

登录行为

控制什么时候自动登录、失败后怎么重试。

登录方式 · 后台请求

开启后，扩展不再依赖页面上的登录框，而是在后台反复请求教务系统：取验证码 → 识别 → 提交登录。 一旦成功，立刻用当前 cookie 打开页面。这就是原 Python 脚本的行为，适合抢课、抢成绩这类需要反复刷的场景。

后台请求模式必须能自动识别验证码：请在上面的「验证码识别」里选择百度 OCR 或自建服务，并填写对应配置。
