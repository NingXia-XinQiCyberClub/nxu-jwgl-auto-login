# 使用边界与脱敏说明

## 1. 使用边界

本仓库是「教务系统登录流程」的教学示例与个人便捷工具，**不是**教务系统的客户端，也不替代学校官方入口。使用时须同时满足：

1. **仅本人账号**：不得用于登录他人账号，不得共享或代管账号。
2. **仅授权环境**：目标系统须为本人有权访问的服务系统；不得对未授权站点发起请求。
3. **不施压**：不得批量登录、并发压测、恶意高频重试。后台静默模式的间隔请保持 ≥1000 ms，次数上限保持默认的低值。
4. **不抢课**：本仓库不提供选课、抢课能力。选课行为受学校教学管理规定约束，自动化抢占他人名额可能构成违纪。
5. **遵守校规**：使用前请确认所在学校对自动化访问信息系统的规定；规定禁止时不得使用。

违反上述任一条的后果由使用者自行承担。

## 2. 脱敏处理

本仓库公开前做了以下处理：

| 项目 | 处理方式 |
| :-- | :-- |
| 学号与密码 | 代码内不出现，改由扩展设置（`chrome.storage.local`）或 `legacy/python/config.py` 提供；`config.py` 已加入 `.gitignore` |
| 百度 OCR AK/SK | 代码内不出现，同上；公开的 `config.example.py` 中留空 |
| 校内备用服务器地址列表 | 段内网 IP 清单已从代码中移除，`KNOWN_MIRROR_HINTS` 置空，需要时由使用者自行添加 |
| 会话票据 / WebVPN 入口 | 不含任何真实票据；文档中的入口地址一律用 `<学校域名>`、`<一串 hex>` 占位 |
| 真实姓名 | 文档与注释中不出现，改为 `<姓名>` 占位 |
| 提交历史 | 推送版本重建为单次初始化提交，不携带含密钥的旧历史 |

## 3. 已知限制

- 只适配 Struts2 风格、表单字段名为 `loginForm.*` 的教务系统，其他实现需改写 `dom-adapter.js` 与 `silent-login.js` 的选择器与字段名。
- 校外访问依赖学校 WebVPN，其 `/https-443/<hex>/` 前缀由会话生成，无法自动推导，需使用者自行复制。
- OCR 识别率受验证码样式影响（真实站点实测：百度高精度版约 90%），失败会重试或回退到手动输入。
- 学校升级系统或调整验证码策略后，本项目可能失效，不承诺持续跟进。
